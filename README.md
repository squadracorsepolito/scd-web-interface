## **🚗 SCD Web Interface**
A **real-time car monitoring dashboard** built with **Next.js, WebSockets, and Canvas API**. The dashboard displays live car data, speed and throttle graphs.

### **🚀 Features**
- **Live WebSocket Data Streaming**
- **Real-time Speed & Throttle Graphs**
- **Interactive Map**
- **Steering Wheel Visualization**
- **Reconnection Handling**
---

## **🛠️ Installation**
### **1️⃣ Clone the Repository**
```bash
git clone https://github.com/squadracorsedriverless/scd-web-interface.git
cd scd-web-interface
```

### **2️⃣ Install Dependencies**
```bash
npm install
```

### **3️⃣ Start the Development Server**
```bash
npm run dev
```
This starts the Next.js development server at **`http://localhost:3000`**.

---

## **🖥️ How to Use**
1. **Run your WebSocket server** (default: `ws://127.0.0.1:9090`)
2. Open **`http://localhost:3000`** in your browser
